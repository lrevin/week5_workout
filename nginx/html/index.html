WEEK 5 · CAPSTONE

Build Up — 건설 현장 진척 보고 앱

누적 조회수 불러오는 중

프로젝트 소개

Build Up은 건설 현장의 작업자·현장 관리자·본사가 공정 진행률, 작업일보, 사진·첨부 문서, 자재 요청을 한 앱에서 주고받는 진척 보고 서비스입니다. 전화·메신저·엑셀로 흩어져 있던 현장 보고를 한곳에 모으고, 사진 촬영 시각과 제출 위치로 허위·지연 보고를 확인해 본사가 현장 상황을 빠르고 정확하게 파악할 수 있도록 합니다.

주요 기능

  • 역할 4가지: 작업자 / 현장 관리자 / 본사 관계자 / 시스템 관리자(웹 전용)
  • 현장 참여: 6자리 참여 코드로 참여, 공정과 가중치를 직접 설정하고 계획 대비 지연 표시
  • 진척 보고: 공정 진행률 + 사진 10장 + 첨부 문서 5개(엑셀·PDF·한글 등) + 날씨·인원·장비
  • 보고 검토: 본사(또는 현장 관리자)가 승인하거나 코멘트와 함께 보완 요청
  • 허위·지연 보고 확인: 사진 촬영 시각(EXIF)과 제출 위치(GPS)로 오래된 사진·현장 밖 제출 표시
  • 자재 요청: 요청 → 현장 관리자 또는 본사가 승인·반려
  • 본사 대시보드: 연결된 현장을 한눈에, 확인 안 한 보고·승인 대기 자재 표시
  • 작업일보 엑셀 내보내기, 휴대폰 알림(Firebase)

사용 기술

안드로이드 앱: React Native · TypeScript
백엔드 API: Spring Boot · Java 17 · MySQL 8 · Spring Security + JWT · BCrypt
웹 대시보드: React · TypeScript · Recharts
인프라·도구: AWS EC2 · RDS · S3, Nginx, Firebase 알림, Swagger, JUnit, GitHub Actions

팀 소개

경동대학교 캡스톤 디자인 3인 팀 — 앱, 서버, 웹 대시보드를 나누어 개발했습니다.
